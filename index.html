Import CSV / TSV

Prepare a CSV file in Excel or Numbers, export it as CSV UTF-8, then select it here. TSV (tab-separated) is also supported. The first row should contain headers.

Recommended columns:
deck, front, back, romaji, example, language, tags

Required: front and back. Column names are case-insensitive. If deck is missing, cards go into “Imported”.

Import notes

The importer handles quoted CSV cells and commas inside quoted fields. Excel workbook (.xlsx) files are not parsed directly in this MVP: export the sheet as CSV UTF-8 first.

FSRS parameter optimization

Optimize the FSRS memory model using your own review history. Optimization runs in this browser; your cards and review logs are not uploaded. For a useful result, build up a few hundred reviews first.

Checking review history and optimizer readiness…

Optimizing changes the parameters used for future scheduling. Existing due dates are left as they are, so your queue will not suddenly change. You can restore the default parameters at any time.

Back up your data

Export a JSON backup containing decks, cards, scheduling state and review history. Save it in Files or another location you control.

Restore a backup

Restoring replaces the current app data. Export a backup first.

Storage and privacy

No account or app server is used. Data lives in this browser's local IndexedDB storage. Browser data can still be removed by iOS or by the user; this is not the same as an encrypted device backup. Export backups regularly.
